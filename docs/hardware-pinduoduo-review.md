# 拼多多 LCDWIKI ES3C35P 商品核对

## 1. 商品信息（来自用户截图）

- 商品平台：拼多多。
- 商品截图价格：约 ¥97。
- 商品 SKU 标注：
  - 电容触摸带喇叭：ES3C35P
  - 电容触摸不带喇叭：ES3C35P-NS
- 屏幕：3.5 英寸 IPS TFT，320×480，ST77922，QSPI。
- 主控：ESP32-S3，8MB OPI PSRAM + 16MB QSPI Flash。
- 音频相关：板载麦克风、ES8311 音频编解码、FM8002E 功放、喇叭接口。
- 其他：MicroSD、USB-C、3.7V 电池接口、I2C 外设接口、扩展 GPIO。

## 2. 结论

**建议作为 Smart_bot 第一版主控候选购买，优先 ES3C35P SKU。**

理由：
1. 价格约 ¥97，明显低于此前考虑的 Waveshare 3.5 英寸板。
2. 主控、屏幕、触摸、音频输入输出和电源管理集成度较高。
3. LCDWIKI 官方规格书和用户手册可查。
4. XiaoZhi ESP32 上游仓库已有独立的 `lcdwiki-es3c35p` 板级配置和初始化源码，降低二次适配成本。

## 3. 下单前向商家确认

请商家逐项文字确认：

1. 发货型号是否为 LCDWIKI ES3C35P，而不是外观相似的其他 ESP32-S3 屏幕板。
2. 是否确实为 8MB PSRAM + 16MB Flash。
3. SKU“带喇叭”是否包含实际的喇叭单元，还是仅表示板载功放和喇叭接口。
4. 是否包含 1.25mm 喇叭接线、USB-C 数据线和 4P 扩展线。
5. 屏幕是否为 ST77922、320×480 QSPI、电容触摸。
6. 是否支持 5V USB-C 供电，板卡是否为全新、无焊接改动。

官方资料清单显示的标准附件为 4P 1.25mm 转 2.54mm 连接线和 Type-C 数据电源线；官方手册说明板上有喇叭接口和功放，但并不能据此保证每个商家 SKU 都附送实体喇叭。因此必须确认。

## 4. 技术注意事项

### 蓝牙规格

部分商品参数写“蓝牙 5.0 BR/EDR + BLE”，但 ESP32-S3 芯片官方规格为 Bluetooth LE，不支持经典蓝牙 BR/EDR。该参数属于商品规格表错误或模板混用。

对 Smart_bot 没有实质影响：
- BLE 用于手机配网、设备配置和低功耗控制。
- Wi-Fi 承担语音和云端通信。
- 不计划用 ESP32-S3 作为蓝牙 A2DP 音箱。

### 屏幕横向安装

屏幕原生 320×480 竖屏。为匹配确认的横向机器人脸，计划将模块整体旋转 90°安装，并实现软件显示旋转和触摸坐标映射。

XiaoZhi 上游已有板级驱动，但其当前配置没有开启软件旋转，不能假设直接烧录后就是横屏。先用原生竖屏固件验收，再做横屏旋转测试，测试通过后才定稿头部外壳。

### 喇叭和供电

官方用户手册说明：
- 板载 ES8311 音频编解码。
- 板载 FM8002E 功放。
- 外接单声道喇叭接口。
- 5V 供电时功放最大输出约 1.5W（8Ω）或 2W（4Ω）。

若 SKU 未附送实体喇叭，后续购买 8Ω 1W 左右的扬声器，并核对 1.25mm 2P 插头。第一版使用稳定 5V USB 供电；舵机必须独立供电，不能从主控板或电池充电端直接取电。
