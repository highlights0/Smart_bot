# 第一阶段硬件选型

## 1. 主控板

优先评估：Waveshare ESP32-S3-Touch-LCD-3.5。

官方资料：
- 产品页：https://www.waveshare.net/shop/ESP32-S3-Touch-LCD-3.5.htm
- 示例工程：https://github.com/waveshareteam/ESP32-S3-Touch-LCD-3.5
- 小智固件对应板级目录：https://github.com/78/xiaozhi-esp32/tree/main/main/boards/waveshare/esp32-s3-touch-lcd-3.5

采购时注意区分相近型号和 PCB 版本，不能仅凭商品标题判断。下单前核对：
- 型号完整名称为 ESP32-S3-Touch-LCD-3.5。
- 屏幕分辨率、方向及控制器与当前固件板级支持一致。
- ESP32-S3、PSRAM、Flash 规格。
- 是否包含麦克风、音频编解码器、扬声器接口。
- 包装是否包含扬声器、摄像头、外壳和电池（不要默认包含）。

## 2. 首批建议采购

首批只购买完成桌面语音验证所需物品：

| 物品 | 数量 | 备注 |
| --- | ---: | --- |
| ESP32-S3-Touch-LCD-3.5 | 1 | 主控和屏幕 |
| USB-C 数据线 | 1 | 必须支持数据传输 |
| 稳定 5V USB 电源 | 1 | 按官方板卡输入要求选择 |
| 兼容扬声器 | 1 | 先确认包装是否附带及板端接口/阻抗要求 |
| 杜邦线/小型连接线 | 少量 | 仅用于必要扩展 |

预算仅作为采购规划，具体以淘宝/拼多多当时商品 SKU、运费和包装为准。

## 3. 暂缓采购

以下项目等主控板到货并完成测量后再买：

- MG90S 或其他舵机。
- PCA9685 舵机驱动板。
- 独立舵机电源。
- 锂电池及充电配件。
- 摄像头。
- 3D 打印外壳。
- 颈部轴承、齿轮和复杂传动件。

舵机不能只按网上常见推荐型号购买。需要根据头部质量、重心偏距、目标角速度和机械支撑方式计算扭矩，并设置独立供电、限位和堵转保护。

## 4. 到货验收

1. 检查 PCB 型号、版本和外观。
2. 使用 USB 数据线连接电脑，确认串口枚举。
3. 烧录官方示例，验证屏幕和触摸。
4. 验证麦克风录音和扬声器播放。
5. 验证 Wi-Fi 连接和稳定性。
6. 记录主板外形、安装孔、接口高度和屏幕外形尺寸。
7. 拍摄正反面照片，作为后续外壳建模依据。
