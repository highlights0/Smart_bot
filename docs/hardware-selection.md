# 第一阶段硬件选型

## 1. 当前首选：LCDWIKI ES3C35P

用户提供的拼多多商品详情截图标注：

- SKU：电容触摸带喇叭 ES3C35P；电容触摸不带喇叭 ES3C35P-NS。
- 截图显示价格：约 ¥97。
- 主控：ESP32-S3，双核 Xtensa LX7，最高 240MHz。
- 存储：8MB OPI PSRAM + 16MB QSPI Flash（N16R8）。
- 屏幕：3.5 英寸 IPS TFT，320×480，ST77922，QSPI。
- 触摸：电容触摸，I2C。
- 音频：板载 MEMS 麦克风、ES8311 音频编解码、FM8002E 功放、外接喇叭接口。
- 扩展：MicroSD、电池接口、I2C 外设接口、GPIO 扩展接口。
- 供电：USB-C 5V；支持 3.7V 聚合物锂电池。

官方资料：
- 产品规格书：https://www.lcdwiki.com/res/ES3C35P/3.5inch_IPS_ESP32-S3产品规格书_V1.0.pdf
- 用户手册：https://www.lcdwiki.com/res/ES3C35P/3.5inch_IPS_ESP32-S3用户手册.pdf
- XiaoZhi 对应板型：https://github.com/78/xiaozhi-esp32/tree/main/main/boards/lcdwiki-es3c35p

### 1.1 与项目的匹配度

这块板比之前考虑的 Waveshare 3.5 更符合当前预算，并且不是只有屏幕的裸开发板：音频编解码、麦克风、功放、触摸、Wi-Fi、BLE 和电池管理均已集成。

XiaoZhi ESP32 上游仓库当前已有独立板型目录：
`main/boards/lcdwiki-es3c35p/`

其中包含：
- `config.h`
- `config.json`
- `lcdwiki-es3c35p.cc`
- `README.md`

因此可以复用上游现有的 QSPI ST77922 显示、触摸、ES8311 音频和 Wi-Fi 语音链路，不需要从零适配硬件。

### 1.2 重要注意事项

1. **蓝牙参数存在错误风险**：商品截图/部分规格资料写了 BR/EDR + BLE，但 ESP32-S3 芯片本身只支持 Bluetooth LE，不支持经典蓝牙 BR/EDR。对本项目的 BLE 配网和控制没有影响，但不能把它当作蓝牙音箱/耳机 A2DP 主机使用。
2. **屏幕原生是竖屏**：320×480，ST77922 QSPI。参考人偶图是横向脸部，因此计划将整个模块物理旋转 90°安装，并开发 LVGL 软件旋转和触摸坐标变换。当前上游板级配置使用 `DISPLAY_SWAP_XY=false`，显示端 `sw_rotate=0`，不能假设现成固件烧录后就会自动横屏。先验证旋转，再打印外壳。
3. **屏幕窗口尺寸存在参数冲突**：拼多多截图写的可视窗口尺寸约 45.20 × 59.45 mm，但 LCDWIKI 官方规格书写的是约 49.96 × 74.44 mm，且有效显示区为 48.96 × 73.44 mm。拼多多这组窗口尺寸甚至小于其标注的有效显示区，数据逻辑不一致。下单前要求商家确认是否为 ES3C35P 原版屏幕，并提供实物尺寸图/PCB 背面照片。不要按拼多多这组可视窗口数据设计外壳。\n4. **喇叭 SKU 必须问清楚**：官方手册确认板上有喇叭接口和功放，但官方配件清单只列 4P 转接线和 Type-C 线。拼多多标题中的“带喇叭”可能指附带喇叭单元，也可能只是带音频输出功能；下单前让商家明确拍照确认是否随板附送实体喇叭。
4. **蓝牙无需为 BR/EDR 加价**：本项目语音数据走 Wi-Fi，手机配网/配置用 BLE 即可。
5. **不要把舵机接在板载电源上**：舵机使用独立 5V 电源，和主板共地。首批暂不买舵机。
6. **不要先买电池**：先用 USB-C 5V 供电完成验证。后续确认电池空间、保护和续航需求后再选 3.7V 聚合物电池。

### 1.3 屏幕与面板尺寸

LCDWIKI 官方规格给出的模块外形约为 54.5 × 101.5 × 10 mm；显示有效区域约 48.96 × 73.44 mm、官方可视窗口约 49.96 × 74.44 mm。拼多多截图中另列的 45.20 × 59.45 mm 与官方规格不符，必须向卖家核实。模块物理旋转 90°后，板子约 101.5mm 宽、54.5mm 高，显示有效区域约 73.44mm 宽、48.96mm 高。

头部外壳不能按 3.5 英寸对角线直接推算开孔。需到货后实测 PCB、玻璃、排线、接口和安装孔。

## 2. 首批采购建议

| 物品 | 数量 | 预算/说明 |
| --- | ---: | --- |
| LCDWIKI ES3C35P | 1 | 用户截图约 ¥97；优先选择 ES3C35P SKU |
| USB-C 数据线 | 1 | 必须支持数据传输；先确认包装是否包含 |
| 稳定 5V 2A USB 电源 | 1 | 首版 USB 供电 |
| 8Ω 1W 或符合功放规格的小喇叭 | 1 | 仅当 SKU 没有附送实体喇叭时购买；接口为 1.25mm 2P，需核对插头 |
| 少量连接线 | 1套 | 后续 I2C 扩展用 |

官方手册说明板载 FM8002E 功放在 5V 供电时，最大输出约 1.5W（8Ω）或 2W（4Ω）。实际选喇叭时优先采用 8Ω、1W 左右的常见小喇叭，避免超过额定功率。

## 3. 后续再采购

以下项目等主控板到货并完成测量后再买：

- MG90S 或其他舵机。
- PCA9685 舵机驱动板（后续可评估通过板载 I2C 扩展口连接）。
- 独立舵机电源。
- 3.7V 锂电池及配件。
- 摄像头。
- 3D 打印外壳。
- 颈部轴承、齿轮和复杂传动件。

舵机不能只按网上常见推荐型号购买。需要根据头部质量、重心偏距、目标角速度和机械支撑方式计算扭矩，并设置独立供电、限位和堵转保护。

## 4. 固件目标与编译

必须使用 XiaoZhi 的 LCDWiki 专用板型：
`lcdwiki-es3c35p`

参考命令：
```bash
python scripts/build.py lcdwiki-es3c35p --zip
```

禁止误选以下不同板型：
- `waveshare/esp32-s3-touch-lcd-3.5`
- `waveshare/esp32-s3-touch-lcd-3.5b`
- `waveshare/esp32-s3-touch-lcd-3.49`

虽然都使用 ESP32-S3，但屏幕控制器、QSPI/SPI 总线和 GPIO 分配不同，固件不能混刷。

## 5. 到货验收

1. 检查 PCB 丝印和商品型号，确认 ES3C35P，而不是 ES3C35P-NS 或其他相似板。
2. 检查 8MB PSRAM、16MB Flash 型号信息（可通过固件/串口日志辅助确认）。
3. 使用 USB 数据线连接电脑，确认串口枚举。
4. 烧录 LCDWiki 专用 XiaoZhi 固件，验证屏幕、触摸、麦克风和音频输出。
5. 验证 Wi-Fi 和 BLE。
6. 测量主板外形、安装孔、接口高度、屏幕玻璃和排线。
7. 拍摄正反面照片，作为后续外壳建模依据。
8. 先保持竖屏完成基础验收，再测试 90°横向显示和触摸映射。
