# 产品外观与结构方向

## 1. 已确认的视觉方向

以用户在项目讨论中提供的桌面机器人参考图为设计基准。该图是外观方向参考，不代表已完成尺寸测绘或可直接照搬其内部结构。

### 1.1 外观语言

- 整体形态：桌面式、头部明显、底座稳固。
- 头部：白色圆角方盒，边缘圆润，略带后仰角度。
- 正面：黑色一体化面板，屏幕区域居中偏上。
- 表情：黑底白色简笔表情，两个眼睛和一条嘴线作为默认待机脸。
- 颈部：灰色圆柱/转台结构，连接头部与底座。
- 底座：灰色低矮宽底座，前后方向有足够支撑面积。
- 细节：侧面扬声器孔、USB 接口；正面下边缘可预留摄像头或状态指示灯位置。

### 1.2 不采用的方向

- 不做猫耳、兔耳等动物拟人造型。
- 不做传统小人形身体和四肢。
- 不把屏幕做成狭长条形；表情屏需要接近方形或横向矩形的视觉区域。
- 不在第一版增加不必要的摄像头、手臂或复杂机械结构。

## 2. 屏幕与头部比例

拟选 3.5 英寸 320×480 屏幕为头部正面显示单元。该屏幕为竖向比例，不能未经验证就直接等同于参考图中的横向显示区域。

设计时需要先确定屏幕的实际可视区域、边框、排线/接口方向和安装孔位，再通过外壳面板开窗与屏幕旋转方向形成参考图的视觉效果。若旋转 90°使用，必须先验证驱动方向、触摸坐标方向和固件 UI 旋转支持。

外壳尺寸不能只按屏幕标称 3.5 英寸估算，必须以收到的实物和官方机械图为准。

## 3. 机械分件建议

第一版拆成四个可独立打印/维护的部分：

1. 前面框：固定屏幕，形成黑色正面面板边界。
2. 后壳：容纳主板、线束和扬声器，预留拆装螺丝。
3. 颈部组件：先做固定结构，保留后续舵机安装空间。
4. 底座：容纳配重和走线，保证桌面稳定。

屏幕前面板应有压边或支撑台阶，避免仅靠胶水承受屏幕重量。后壳需留出 USB 插拔空间和散热间隙。

## 4. 运动结构规划

阶段一：头部固定，不装舵机。

阶段二：增加左右旋转（Yaw）：
- 舵机安装在底座或颈部。
- 头部重心尽量落在旋转轴附近。
- 机械限位与软件限位同时存在。
- 线束通过旋转中心附近布置，避免缠绕。

阶段三：评估上下俯仰（Pitch）：
- 只有在头部重量、重心和支撑轴确认后再选舵机。
- 头部较重时优先使用双侧支撑轴，不让单个微型舵机直接承担全部弯矩。

## 5. 外观材质与颜色

- 头部外壳：哑光白色 PLA/PETG。
- 正面：黑色亚克力/黑色打印框 + 屏幕。
- 颈部和底座：哑光深灰色。
- 螺丝尽量隐藏，维修螺丝放在后壳或底部。

## 6. 待实物确认的尺寸

- 屏幕外形尺寸、可视区、厚度及安装孔。
- 开发板 PCB 外形和连接器高度。
- 喇叭直径、厚度和出音方向。
- 主板、喇叭和线束的空间冲突。
- 头部总重量及三维重心。
- 底座可用空间和稳定性。

在这些数据确认前，不输出最终 STL，也不锁定舵机型号。
