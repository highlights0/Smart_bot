# 产品外观与结构方向

## 1. 已确认的视觉方向

以用户提供的桌面机器人参考图为设计基准。该图是外观方向参考，不代表已完成尺寸测绘或可直接照搬其内部结构。

### 1.1 外观语言

- 整体形态：桌面式、头部明显、底座稳固。
- 头部：白色圆角方盒，边缘圆润，略带后仰角度。
- 正面：黑色一体化面板，屏幕区域居中偏上。
- 表情：黑底白色简笔表情，两个眼睛和一条嘴线作为默认待机脸。
- 颈部：灰色圆柱/转台结构，连接头部与底座。
- 底座：灰色低矮宽底座，前后方向有足够支撑面积。
- 细节：侧面扬声器孔、USB 接口；正面下边缘可预留摄像头或状态指示灯位置。

### 1.2 不采用的方向

- 不做猫耳、兔耳等动物拟人造型。
- 不做传统小人形身体和四肢。
- 不把屏幕做成狭长条形；表情屏需要接近方形或横向矩形的视觉区域。
- 不在第一版增加不必要的摄像头、手臂或复杂机械结构。

## 2. 屏幕与头部比例

当前优先采用 LCDWIKI ES3C35P 3.5 英寸模块：
- 原生分辨率：320×480，竖屏。
- 显示驱动：ST77922，QSPI。
- 模块外形约：54.5 × 101.5 × 10 mm。
- 有效显示区约：48.96 × 73.44 mm。

参考图的脸部是横向比例。计划将整个开发板在头部内物理旋转 90°，让板卡外形横向布置，再通过固件实现显示软件旋转及触摸坐标映射。该方案需先在实物上验证，不能仅修改外壳方向就认为 UI 会自动横屏。

上游 XiaoZhi 的 LCDWiki 板型已固定 `DISPLAY_SWAP_XY=false`，当前 LVGL 显示配置也未开启软件旋转。因此需要单独完成：
1. 显示内容旋转 90°。
2. 触摸坐标旋转、镜像和边界校准。
3. 旋转后的动画性能与内存占用测试。
4. 语音状态 UI 在横屏布局下的适配。

如果软件旋转性能或触摸映射不理想，再评估保持竖屏外观或改用其他横屏屏幕；不要在未验证前定稿外壳。

外壳尺寸不能只按屏幕标称 3.5 英寸估算，必须以收到的实物和官方机械图为准。

## 3. 机械分件建议

第一版拆成四个可独立打印/维护的部分：

1. 前面框：固定屏幕，形成黑色正面面板边界。
2. 后壳：容纳主板、线束和扬声器，预留拆装螺丝。
3. 颈部组件：先做固定结构，保留后续舵机安装空间。
4. 底座：容纳配重和走线，保证桌面稳定。

屏幕前面板应有压边或支撑台阶，避免仅靠胶水承受屏幕重量。后壳需留出 USB 插拔空间和散热间隙。

## 4. 运动结构规划

阶段一：头部固定，不装舵机。

阶段二：增加左右旋转（Yaw）：
- 舵机安装在底座或颈部。
- 头部重心尽量落在旋转轴附近。
- 机械限位与软件限位同时存在。
- 线束通过旋转中心附近布置，避免缠绕。

阶段三：评估上下俯仰（Pitch）：
- 只有在头部重量、重心和支撑轴确认后再选舵机。
- 头部较重时优先使用双侧支撑轴，不让单个微型舵机直接承担全部弯矩。

## 5. 外观材质与颜色

- 头部外壳：哑光白色 PLA/PETG。
- 正面：黑色亚克力/黑色打印框 + 屏幕。
- 颈部和底座：哑光深灰色。
- 螺丝尽量隐藏，维修螺丝放在后壳或底部。

## 6. 待实物确认的尺寸

- 屏幕外形尺寸、可视区、厚度及安装孔。
- 开发板 PCB 外形和连接器高度。
- 喇叭直径、厚度和出音方向。
- 主板、喇叭和线束的空间冲突。
- 头部总重量及三维重心。
- 底座可用空间和稳定性。

在这些数据确认前，不输出最终 STL，也不锁定舵机型号。
