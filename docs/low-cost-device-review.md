# 低成本成品候选：拼多多 159 元小智 AI 机器人

## 1. 商品截图信息

用户提供的拼多多商品详情截图显示：
- 商品名称宣传：小智 AI 机器人。
- 优惠券后价格：约 ¥159（截图时）。
- 主控：ESP32-S3 N16R8（截图标注 8MB PSRAM + 16MB Flash）。
- 屏幕：2.0 英寸，240×320，ST7789。
- 摄像头：商品宣传图显示摄像头，商品参数型号标注 GC0308（需卖家确认它指摄像头传感器型号）。
- 麦克风：双麦克风。
- 扬声器：8Ω、1W。
- 电池：1000mAh。
- 外壳：透明外壳。
- 商品宣传：24 种语言、100+ 音色、语音打断、OTA 等。
- 商品截图给出的外壳尺寸约 70×42×24mm，主板尺寸约 54.2×93.5mm。

以上为商品宣传信息，不代表已经独立验证。价格和优惠可能随时变化。

## 2. 初步结论

**值得作为低成本原型机候选，但不能仅凭商品详情就认定可刷自定义固件或接入自建/第三方小智服务端。**

优点：
1. ¥159 的整机价格包含主控、屏幕、摄像头、双麦克风、扬声器、电池和外壳（以实物包装为准）。
2. ESP32-S3 N16R8 的内存规格足够运行 ESP-IDF、LVGL 和小智类语音客户端。
3. 已有屏幕、音频、摄像头和电池，能降低首轮硬件集成成本。
4. 可先作为语音交互和云端 API 体验验证设备。

风险：
1. 商品未提供可核对的原理图、GPIO 引脚表、音频编解码芯片型号和完整固件源码。
2. ESP32-S3 + N16R8 并不意味着可直接使用其他 ESP32-S3 板型固件；屏幕、音频、摄像头、电源和 GPIO 都需要匹配。
3. 商品宣传“支持 OTA”不等于允许用户更换 OTA 地址、WebSocket 服务端或第三方 API。
4. USB-C/下载烧录接口是否开放、是否有 USB CDC/USB-JTAG/串口下载通道，需要卖家确认。
5. 摄像头标注 GC0308 需确认具体传感器和驱动方式。
6. 屏幕只有 2 英寸，240×320，明显小于原先考虑的 3.5 英寸 ES3C35P。旋转 90°后可形成横向 320×240 逻辑画面，但实际显示面积仍较小，不适合直接复刻参考图中大面积面部屏幕的比例。
7. 1000mAh 电池的续航宣传需要实际测试；连续联网语音、屏幕和摄像头会增加功耗。

结论：
- 追求最低成本、先验证对话体验：159 元成品更有吸引力。
- 追求参考图的大面积面部屏幕和可控固件：ES3C35P 更合适。
- 不应只比较主控芯片和内存；板级驱动、屏幕尺寸、音频链路和固件开放程度才决定开发成本。

## 4. 参考开源项目：M5Stack StackChan

官方资料：
- https://github.com/m5stack/StackChan
- https://docs.m5stack.com/zh_CN/StackChan

StackChan 是一个真实的开源桌面 AI 机器人项目，官方仓库包含固件、遥控器、移动端 App 和服务端代码。它使用 CoreS3，具备 2 英寸屏幕、GC0308 摄像头、双麦克风、1W 扬声器，并且机器人身体带有舵机和电池。

但拼多多商品与 StackChan 并非同一块硬件：
- StackChan/CoreS3 官方规格使用 ILI9342C/ILI9342E，320×240。
- 拼多多商品标注 ST7789，240×320。
- StackChan 官方身体电池为 550mAh，拼多多商品标注 1000mAh。
- StackChan 有独立舵机身体，拼多多图片显示的是透明小盒形态。

因此 StackChan 可作为产品交互、表情、运动和软件架构参考，不能假设其固件可直接烧录到拼多多商品。

## 5. 下单前必须问卖家的问题

1. 是否可以通过 USB-C 或板载下载接口自行烧录 ESP-IDF 固件？是否提供烧录教程和完整固件恢复包？
2. 是否提供原理图、PCB 引脚表、屏幕 ST7789 的 SPI 引脚、触摸控制器型号和触摸 I2C 地址？
3. 双麦克风使用什么音频 ADC/Codec 芯片？扬声器使用什么 I2S 功放芯片？I2S GPIO 分配是什么？
4. 摄像头是否确实为 GC0308？使用 DVP 还是其他接口？GPIO 分配是否公开？
5. 固件是否基于开源 XiaoZhi ESP32？能否修改 WebSocket 服务端地址、OTA 地址和设备激活流程？
6. 是否可以接入用户自己的小智服务端或兼容 XiaoZhi WebSocket 协议的服务端，而不是只能使用商家云服务？
7. 1000mAh 电池是否包含在 ¥159 SKU 内？是否可拆换？是否有电池保护和充电管理资料？

## 6. 采购决策规则

- 如果卖家确认可以自行烧录，并提供硬件引脚/芯片资料，且可切换到自定义小智服务端：建议优先买 1 台做原型验证。
- 如果只能使用商家云服务，不能改服务端、不能刷自定义固件：不建议作为 Smart_bot 的主开发平台；最多作为体验参考。
- 如果卖家不提供引脚表和音频芯片型号：不要承诺可直接适配上游小智固件。
- 收货后先备份原厂固件，再尝试刷写；保留恢复原厂的办法。
