# Smart Bot｜桌面 AI 陪伴机器人

一个以 ESP32-S3 为核心、通过云端 API 提供智能对话能力的桌面陪伴机器人项目。

## 产品方向

第一版外观以用户确认的参考图为准：白色圆角方形头部、正面黑色屏幕面板、极简白色表情、灰色短颈部和稳定底座。整体偏简洁、温和的桌面智能设备，不做传统 Q 版人形身体，也不做动物造型。

关键外观特征：

- 横向圆角方形头部，白色外壳。
- 正面大面积黑色屏幕面板。
- 屏幕显示简洁的眼睛、嘴部和情绪动画。
- 头部安装在短颈部转台上，支持左右转动；后续评估上下俯仰。
- 灰色底座，重心低、桌面放置稳定。
- 侧面预留扬声器出音孔、USB 接口和维护结构。
- 正面下缘可预留摄像头/状态指示灯位置，第一版不强制采购摄像头。

## 第一阶段硬件选型

当前优先选择用户在拼多多找到的 **LCDWIKI ES3C35P 3.5 英寸 ESP32-S3 模块**，截图价格约 ¥97。该商品参数与 LCDWIKI 官方 ES3C35P 规格书一致，并且 XiaoZhi ESP32 上游仓库已经提供独立板型支持。

- 型号：ES3C35P（优先选择带喇叭的 SKU；下单前确认是否真的附送喇叭单元）。
- 主控：ESP32-S3，8MB OPI PSRAM，16MB Flash。
- 屏幕：3.5 英寸 IPS，320×480，ST77922，QSPI，电容触摸。
- 音频：板载 MEMS 麦克风、ES8311 编解码、FM8002E 功放和喇叭接口。
- 无线：2.4GHz Wi-Fi + BLE（ESP32-S3 不支持经典蓝牙 BR/EDR）。
- 供电：USB-C 5V；支持后续接入 3.7V 聚合物锂电池。

固件板型必须选择 `lcdwiki-es3c35p`，不能误刷 Waveshare 3.5 / 3.5B 固件。

## 第一阶段技术路线

- 固件基础：复用 `78/xiaozhi-esp32` 的 `lcdwiki-es3c35p` 板级驱动和语音链路。
- 服务端：优先使用 `xinnan-tech/xiaozhi-esp32-server`，采用云端 ASR / LLM / TTS API，不运行本地大模型。
- UI：基于 LVGL 开发机器人表情、待机动画和交互状态。
- 屏幕方向：模块原生为 320×480 竖屏；为了匹配确认的横向机器人脸，计划物理旋转模块 90°安装，并在固件中实现显示软件旋转及触摸坐标映射。该项必须先在开发板上验证。
- 机械：先完成固定头部样机，再增加舵机转头机构。
- 供电：第一版 USB 5V 供电；舵机后续独立供电，电池最后评估。

## 设计原则

1. 先复用成熟开源代码，避免重复开发音频、网络和屏幕底层驱动。
2. 固件、服务端配置和机械结构文档分离。
3. API 密钥只放在服务端，不写入固件、不提交到仓库。
4. 不在未确认实物尺寸、重量和重心前定稿外壳与舵机规格。
5. 所有 Git Commit 说明使用中文。
